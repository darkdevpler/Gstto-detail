# GST API

Simple GSTIN API wrapper built with Node.js and Express.

## Developer

darkdevpler02

## Features

- GSTIN lookup endpoint
- JSON response
- GSTIN validation
- Error handling
- Health check
- Developer information
- Upstream `source` and `credit` fields are not returned
